# Avinandan Pal — Robotics & Applied AI Portfolio

A lightweight, responsive portfolio website highlighting projects across applied AI, computer vision, robotics, and product design.

## Live site

After enabling GitHub Pages, the site is available at the Pages URL shown under **Settings → Pages**.

## What's inside

- Responsive single-page layout
- Project cards with direct repository links where code is public
- Mobile navigation and scroll progress indicator
- Reduced-motion support for accessibility
- GitHub Actions workflow for deploying the static site to GitHub Pages

## Run locally

No build step is required.

1. Clone this repository.
2. Open `index.html` in a browser, or serve the directory with a local static server.

For example, with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Update the portfolio

Edit `index.html` to update the intro, links, projects, skills, and timeline. Prefer linking each project card to the exact repository or live demo rather than to the GitHub profile homepage. Clearly label private, planned, and in-progress work so visitors can distinguish it from finished, public projects.

## Deployment

The workflow in `.github/workflows/static.yml` deploys the repository to GitHub Pages when changes are pushed to `main`, and can also be run manually from the Actions tab.
